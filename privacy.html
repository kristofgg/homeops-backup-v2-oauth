Privacy Policy

HomeOps Backup V2

HomeOps Backup V2 is a private, personal, non-commercial application used only by its owner to back up a personal homeserver to Google Drive.

Data accessed

The application may access Google Drive files and folders as required to create, list, verify, download, replace, or remove backup data belonging to the application owner.

How the data is used

Google Drive access is used solely for personal backup, integrity verification, retention, and disaster-recovery operations. The application does not use Google data for advertising, profiling, analytics, or any unrelated purpose.

Data sharing

No Google user data is sold, rented, shared with advertisers, or disclosed to third parties by HomeOps Backup V2, except where required by law or where Google itself processes data as the storage provider.

Storage and security

Authentication credentials are kept on the owner's private homeserver and are not published in this repository or website. Backup data is protected using the security controls of the backup system and Google Drive. Application/configuration backups use encrypted backup repositories; other disaster-recovery artifacts are handled only for the owner's recovery workflow.

Users

This application is not offered to the public. It has no public account-registration system and is intended for use only by its owner.

Revoking access

The owner can revoke the application's Google Account access at any time through Google Account security settings. Backup files stored in Google Drive can also be deleted by the owner.

Changes

This policy may be updated if the backup workflow changes. The current version is published on this site.
