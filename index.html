HomeOps Backup V2

Private personal backup integration

HomeOps Backup V2 is a private, non-commercial application used by its owner to create and store encrypted backups of a personal homeserver.

The application uses Google Drive only as an off-site backup destination and recovery source. It is not offered as a service to the public and does not provide user registration or third-party access.

Backup content is encrypted before or as part of the backup workflow where applicable, and Google Drive access is used only for backup, integrity verification, and disaster-recovery operations.
